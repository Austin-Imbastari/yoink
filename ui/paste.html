About Yoink ♡

Yoink grabs the audio from any link — YouTube, TikTok, Instagram, SoundCloud & more — and drops it straight into your Set as a WAV. No browser, no downloader, no file hunting.

  1. paste a link
  2. trim the bit you want — scroll to zoom, drag to pan, ▶ to loop it
  3. check the BPM & key (tap to fix the tempo)
  4. pick warp / loop, then drop into set ♪
